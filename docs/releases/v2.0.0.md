# Pulso 2.0.0

**Estúdio de automação para Windows. Grave, edite, reproduza e compile macros.**

Pulso é um gravador e reprodutor de macros — uma evolução do conceito do TinyTask,
com interface moderna, linha do tempo editável, atalhos globais configuráveis e
compilação da macro em um `.exe` autônomo.

## Download

| Edição | Arquivo | Tamanho | Requisito |
|---|---|---|---|
| Portátil | `Pulso.exe` | ~430 KB | [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) |
| Autocontida | `Pulso-selfcontained.exe` | ~62 MB | Nenhum — só Windows x64 |

> Se o `Pulso.exe` não abrir, use a edição **autocontida**.

## Destaques

- **Desfazer e refazer** (`Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z`), com 40 passos.
- **Duplicar selecionados** (`Ctrl+D`) repetindo o bloco logo depois.
- **Arquivos recentes** no menu Arquivo (até 8 entradas).
- **Apagar tudo** em um clique (`Ctrl+Del`), na barra lateral, no topo ou no menu.
- Gravação global de mouse e teclado por hooks de baixo nível, com timestamps reais.
- Linha do tempo editável: editar evento, remover, inserir pausa, escalar tempo.
- Reprodução com velocidade de 5% a 2000%, repetições, modo contínuo e atrasos.
- Coordenadas relativas e envio direto à janela gravada (`PostMessage`).
- Teclas por scan code — melhor compatibilidade com jogos.
- **F12** interrompe tudo, sempre.
- Exportação `.pulso` (macro + preset) e compilação `.exe` via CLI.
- Importação e exportação do formato TinyTask `.rec`.
- Tema escuro, HUD compacto, bandeja do sistema e modo sempre no topo.
- CLI com `--selftest`, `--smoke`, `--demo`, `--compile`, `--play`.
- 12 testes internos; CI verde no Windows.

## Atalhos padrão

| Ação | Atalho |
|---|---|
| Gravar / parar | `Ctrl+Alt+R` |
| Reproduzir | `Ctrl+Alt+P` |
| Pausar / continuar | `Ctrl+Alt+Espaço` |
| Parar tudo | `Ctrl+Alt+S` |
| Modo compacto | `Ctrl+Alt+M` |
| Emergência | `F12` |

Todos configuráveis em **Ferramentas → Configurações**.

## Como usar

1. Execute `Pulso.exe` (portátil, sem instalador).
2. Aperte `Ctrl+Alt+R`, execute a sequência e aperte `Ctrl+Alt+R` de novo.
3. Ajuste velocidade e repetições e aperte `F5`.
4. Para compartilhar: **Arquivo → Exportar macro pronta.** (`.pulso`).
5. Para gerar um executável independente:

   ```powershell
   Pulso.exe --compile minha-macro.gmt minha-macro.exe
   ```

## Verificação de integridade

Baixe o `SHA256SUMS.txt` e confira:

```powershell
Get-FileHash .\Pulso.exe -Algorithm SHA256
Get-FileHash .\Pulso-selfcontained.exe -Algorithm SHA256
```
